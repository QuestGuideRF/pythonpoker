# Покер на Python
Игра в покер, написанная на Python (полный проект)

## 🎮 ПОКЕР НА PYTHON!

Игра в покер игрока против ИИ, написанная на Python 3 с использованием библиотеки NumPy.

## 📋 Как играть?

Это упрощённая версия игры для двух игроков: человек против компьютера (крупье).

### Правила игры:
- Каждый игрок получает карты из колоды (значения от 2 до 11)
- Можно взять до 5 карт в руку
- Выигрывает тот, у кого сумма карт больше
- Можно делать ставки на любую сумму (в пределах имеющихся денег)
- Игра продолжается до тех пор, пока у одного из игроков не закончатся деньги

### Начальные условия:
- **Игрок**: 500 монет
- **Крупье**: 1200 монет

## 🎯 Инструкция по запуску

### Шаг 1: Установка зависимостей

Убедитесь, что у вас установлен Python 3 и библиотека NumPy:

```bash
pip install numpy
```

### Шаг 2: Запуск игры

Запустите файл `PokerPython.py`:

```bash
python PokerPython.py
```

Или просто дважды кликните на файл `.py` в проводнике Windows.

## 🎲 Интерфейс игры

### Главное меню

При запуске вы увидите главное меню с двумя опциями:
- **1. НАЧАТЬ** - начать новую игру
- **2. ВЫХОД** - выйти из игры

### Игровое меню

После начала игры отображается следующая информация:

#### Статистика:
- **Деньги** - ваш текущий баланс (начальный: 500)
- **Карты** - количество карт у обоих игроков
- **Партия** - номер текущей партии

#### Информация о крупье:
- Количество карт в руке (значения не показываются)
- Текущий баланс крупье

#### Информация об игроке:
- Ваши карты и их значения
- Сумма всех ваших карт

#### Банк:
- Общая сумма ставок (ваша ставка + ставка крупье)

### Действия игрока:

1. **Взять ещё карту** - получить дополнительную карту (крупье тоже получит карту)
   - Максимум 5 карт в руке

2. **Остаться** - завершить раунд и сравнить результаты
   - Выигрывает тот, у кого сумма карт больше
   - При ничьей никто не проигрывает

3. **Сделать ставку** - поставить деньги на текущую партию
   - Можно поставить любую сумму в пределах вашего баланса
   - Крупье автоматически сделает ставку, равную вашей

4. **Выйти из партии** - завершить игру и посмотреть статистику

## 📊 Результаты игры

Игра завершается в следующих случаях:

1. **Вы выиграли** - у крупье закончились деньги
   - Поздравляем! Вы победили!

2. **Вы проиграли** - у вас закончились деньги
   - Игра завершена

3. **Вы вышли** - вы выбрали выход из игры

В конце игры отображается статистика:
- Количество выигранных партий
- Количество проигранных партий

## 💡 Советы по игре

- **Стратегия**: старайтесь набрать сумму близкую к максимальной (55 при 5 картах), но не переборщите
- **Ставки**: не ставьте все деньги сразу - это рискованно!
- **Карты**: помните, что максимум 5 карт в руке
- **Баланс**: следите за своим балансом и балансом крупье
